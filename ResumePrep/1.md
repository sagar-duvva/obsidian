# **1. Python — AsyncIO Fundamentals**

### **Topic:** Python AsyncIO

### **Sub-Topics:** Event Loop, Tasks, Awaitables

### **BoJo-Style Bullet Points**

• Core idea → cooperative multitasking  
• `await` pauses task → returns control to loop  
• ! Avoid CPU-bound work inside async coroutines  
• ? Check where backpressure might occur  
• Task grouping → `asyncio.gather` for parallel IO

### **Alastair Tracking Summary**

- **Priority:** High
    
- **Status:** In progress
    
- **Next Actions:** Benchmark differences between sequential vs async fetch calls
    

### **Concept Description**

AsyncIO enables non-blocking IO using coroutines and an event loop. Ideal for HTTP calls, DB queries, and any IO-heavy workflow.

### **Important Notes / Gotchas**

- Don’t mix blocking IO with async execution.
    
- Use `asyncio.run()` only once at program entry.
    
- Hard errors to debug: nested event loops inside notebooks.
    

### **Code Example**

```python
import asyncio
import aiohttp

async def fetch(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as r:
            return await r.text()

async def main():
    urls = ["https://example.com", "https://openai.com"]
    results = await asyncio.gather(*(fetch(u) for u in urls))
    print(results)

asyncio.run(main())
```

### **R&D / Experiment Ideas**

- Test async throttling mechanisms for REST APIs.
    
- Evaluate anyIO / trio as alternatives.

### **BoJo-Style Bullet Points**

• Iterators → `__iter__`, `__next__`  
• Generators → syntactic sugar for iterators  
• → Use for streaming data pipelines  
•! Avoid holding large lists in memory  
• Elegant error propagation with `throw()`

### **Alastair Tracking Summary**

- **Priority:** Medium
    
- **Status:** Completed notes
    
- **Next Actions:** Implement lazy ETL pipeline
    

### **Concept Description**

Generators allow stepwise iteration without materializing full collections. Useful in big-data, ETL, and file streaming.

### **Important Notes / Gotchas**

- Generators exhaust after single pass.
    
- Debugging mid-yield states can be tricky.
    

### **Code Example**

```python
def read_large_file(path):
    with open(path) as f:
        for line in f:
            yield line.strip()

for line in read_large_file("big.txt"):
    process(line)
```
