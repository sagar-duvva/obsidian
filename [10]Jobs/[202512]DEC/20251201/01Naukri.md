## Job description

**Experience:** 510 Years  
**Location:** Hyderabad/Gurugram  
**Notice Period:** Immediate  
**Role:** Azure DevOps Engineer  
**Employment Type:** Full-Time / Permanent  
**Job Summary**  
We are looking for an experienced **Azure DevOps Engineer** to support our **Data & Analytics** environment. The ideal candidate must have strong hands-on expertise in Azure DevOps, CI/CD, IaC, Data Factory, Databricks administration, and Azure security/configurations. You will work closely with BI, Data Engineering, and Analytics teams to streamline deployments, optimize performance, automate workflows, and ensure operational excellence.  
**Key Responsibilities**  

- Design, build, and manage **CI/CD pipelines** using Azure DevOps (Repos, Boards, Pipelines).  
    
- Implement and maintain **Infrastructure-as-Code** using ARM Templates, Terraform, or Bicep.  
    
- Manage and monitor **Azure Data Factory** pipelines (ETL/ELT).  
    
- Work with **Microsoft Fabric** (workspaces, pipelines, integrations).  
    
- Handle **Azure Analysis Services / Semantic Models** deployment, scaling & optimization.  
    
- Configure **Azure AD/EntraID** permissions, RBAC, and group-based access for Power BI & services.  
    
- Automate processes using **PowerShell & Python** (approval flows, deployment scripts, pipelines).  
    
- Implement Git workflows, branching strategies, pull requests & versioning best practices.  
    
- Administer **Azure Databricks** (workspace, clusters, performance tuning, security, pipeline integration).  
    
- Manage **Azure Cost Management** — budgets, alerts, tagging strategy & expense allocation.  
    
- Collaborate with BI, Data Engineering & Cloud teams on deployments and production support.  
    
- Prepare and maintain documentation in Confluence.  
    

**Required Technical Skills**  

- Azure DevOps (Repos, Boards, Pipelines, CI/CD)  
    
- ARM Templates / Terraform / Bicep  
    
- Azure Data Factory  
    
- Microsoft Fabric (Pipelines, Workspaces, Data Integration)  
    
- Azure Analysis Services / Semantic Models  
    
- EntraID / Azure AD (RBAC, Groups, Permissions)  
    
- PowerShell & Python automation  
    
- Git (branching, PRs, merge strategies)  
    
- Azure Databricks Administration  
    
- Azure Cost Management (Budgets, Alerts, Tagging)  
    

**Good-to-Have Skills**  

- Docker / Kubernetes / AKS  
    
- Azure Service Bus / Event Grid / Event Hubs  
    
- Azure Functions / Logic Apps  
    
- Azure Monitor, Log Analytics, Application Insights  
    
- Azure Policy, Security & Compliance  
    
- AWS/GCP DevOps familiarity (basic)  
    
- Confluence for documentation  
    

**Soft Skills**  

- Excellent verbal & written communication  
    
- Strong analytical and troubleshooting skills  
    
- Ability to manage multiple tasks and deadlines  
    
- Proactive, self-driven, and adaptable to new technologies  
    
- Strong collaboration with BI/Data teams  
    

**Required Qualification**  

- Bachelor’s degree in engineering/computer science or relevant field  
    
- 5–10 years of hands-on DevOps experience (preferably in Data & Analytics environments)
